# 로르샤흐 연습실 (프로토타입)

AI 내담자와 로르샤흐 검사 시행(반응 단계, 질문 단계)과 Exner 종합체계 채점을 연습하는 PWA입니다.
빌드 도구나 서버 없이 정적 파일만으로 동작합니다.

## 실행

```
cd Desktop/dev/rorschach-practice
python -m http.server 8080
```

브라우저(Chrome 또는 Edge 권장)에서 http://localhost:8080 을 엽니다.
마이크와 서비스 워커는 `localhost` 또는 https에서만 동작하므로 파일을 더블클릭해 열면 안 됩니다.

처음 열면 설정 창이 뜹니다. Anthropic API 키(https://console.anthropic.com)를 넣고 저장하세요.

## 연습 흐름

1. **반응 단계**: "이게 무엇으로 보이나요?"처럼 지시하면 수검자가 음성과 글자로 반응합니다. 반응은 왼쪽 반응 기록에 쌓입니다.
2. **질문 단계**: 반응마다 어디서, 무엇 때문에 그렇게 보였는지 묻습니다. 유도 질문을 하면 수검자가 그냥 동의할 수 있습니다.
3. **채점**: 반응별로 위치, 발달질, 결정인, 형태질, 내용, 특수점수를 입력합니다.
4. **피드백**: 참고 채점과의 비교, 질문 기법 지적, 수검자가 실제로 본 근거, 페르소나 공개.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 |
| `app.js` | 상태 관리, 단계 진행, 음성 입출력 |
| `inkblot.js` | 시드 기반 대칭 잉크반점 생성 (원본 카드 미사용) |
| `persona.js` | 페르소나, 수검자/감독자 프롬프트, 응답 스키마 |
| `scoring.js` | Exner 기호 목록, 채점 비교 |
| `llm.js` | Claude Messages API 호출 (BYOK) |
| `sw.js`, `manifest.webmanifest` | PWA 설치, 오프라인 화면 캐시 |
| `apple-touch-icon.png`, `icon-*.png` | 홈 화면 아이콘 (아이폰은 PNG만 인식) |

## 아이폰에 설치

https 주소에 올린 뒤 Safari로 열고 공유 버튼 → "홈 화면에 추가"를 누릅니다.

- 홈 화면 앱은 Safari와 저장공간이 따로라서 API 키를 앱 안에서 다시 넣어야 합니다.
- 홈 화면 앱에서 음성 인식이 안 되면 마이크 버튼이 숨겨집니다. 그때는 Safari에서 열어 쓰거나 키보드의 받아쓰기(마이크) 버튼을 씁니다.

## 프로토타입 한계

- 음성 인식과 음성 합성은 브라우저 기능(Web Speech API)을 씁니다. Chrome의 음성 인식은 음성을 Google 서버로 보냅니다. 실제 내담자 녹음에는 쓰지 마세요.
- API 키와 기록은 localStorage에 저장합니다. 다음 단계에서 IndexedDB로 옮길 예정입니다.
- LLM은 Claude만 지원합니다. GPT, Gemini는 다음 단계에서 추가합니다.
- 페르소나 1개, 카드 1장.
